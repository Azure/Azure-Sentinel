# Proofpoint On Demand Email Security ASIM EmailEvent Normalization Parser

ARM template for ASIM EmailEvent schema parser for Proofpoint On Demand Email Security.

Filters and normalizes message inspection records in ProofpointPODMessage_CL.
Time filters use the source eventTime, not ingestion time. Recipient filters
inspect To, Cc and Bcc headers. IP prefixes are matched literally, including IPv6.
A continue disposition does not establish final delivery; EventResult is NA.


The Advanced Security Information Model (ASIM) enables you to use and create source-agnostic content, simplifying your analysis of the data in your Microsoft Sentinel workspace.
